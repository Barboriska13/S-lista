# С листа

Тренажёр чтения нот с листа для фортепиано.

- **Играть в браузере:** https://barboriska13.github.io/S-lista/ (MIDI работает в Chrome и Edge)
- **Android:** [скачать S-lista.apk](https://github.com/Barboriska13/S-lista/releases/latest/download/S-lista.apk)

APK собирается автоматически при каждом обновлении `index.html`. MIDI-клавиатура подключается через USB OTG.
